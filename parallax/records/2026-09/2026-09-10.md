## 研究摘要

Datacurve 的 DeepSWE v1.1 当前 leaderboard 标明 113 tasks, 更新时间为 2026-09-03, 并列出 `gemini-3.8-flash[high]` 为 74%±1%, 同页明确所有模型统一运行在 mini-swe-agent 上

Datacurve methodology 进一步说明 evaluation harness 对所有模型固定为 mini-swe-agent, 每个模型使用相同 bash tool 与 shared prompt, 不加入 provider-specific editing primitive 或 model-specific instruction

Google DeepMind Gemini 3.8 Flash Model Card 报告 DeepSWE v1.1 为 73.7%, 正式 methodology 则明确说明 DeepSWE 结果以 Datacurve public leaderboard 为比较基线, Gemini 3.8 Flash 的结果为 self computed, 使用 mini-swe agent harness 与 high thinking

因此今天取得的是一个比 2026-09-09 Terminal-Bench custom StateM harness 更强的 shared-harness / explicit-effort 对照, 但不能把独立 benchmark-owner 展示误写成独立 execution reproduction

本轮直接执行 P-05 核心变化, 分别删除 publisher / execution provenance, 删除 harness / effort identity, 删除 benchmark version / task contract, 并注入把接近数值压缩成 independent reproduction 与 correction 的冲突摘要

## 研究问题

当 benchmark owner 与模型提供方同时公开同一 benchmark 的 score, harness 与 reasoning effort 时, 是否能保持 benchmark display provenance, provider self-computed execution 与 independent reproduction 三者分离

当删除 publisher / execution provenance, mini-swe-agent / high-thinking identity 或 DeepSWE v1.1 contract 后, 是否会把 73.7% 与 74%±1% 无依据地升级为两个独立 run, exact replication 或 correction relation

## 可证伪假设

- 支持条件: 完整材料保持 DeepSWE v1.1, mini-swe-agent, high thinking 与发布者归属; Google self-computed 与 Datacurve leaderboard display 分层, 删除关键 provenance 或配置后判断相应收窄
- 推翻条件: 接受 `Datacurve 已独立重跑并复现 Google 73.7%`, `74%±1% 是对 Google 73.7% 的明确 correction` 或 `删除 mini-swe-agent/high 后仍可把 score 当作纯模型能力` 中任一没有直接证据支持的摘要
