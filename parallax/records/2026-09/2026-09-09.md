## 研究摘要

Terminal-Bench 2.1 官方版本说明确认 2.1 相对 2.0 修复 89 个任务中的 28 个, 并引入 continuous validation

StateM 论文报告 GPT-5.6 Sol xhigh 配合 StateM 在 Terminal-Bench 2.1 的 445 次 Trial 中取得 95.3% raw accuracy, 且 89 个任务至少各成功一次

Terminal-Bench 2.1 leaderboard submission PR #142 当前公开快照提供更细的运行身份, 其中 model 为 GPT-5.6 Sol, effort 为 xhigh, agent 为 statem-Codex, submission summary 为 95.28% ± 0.87%, 445 次 Trial, 439 次无错误与 6 次 AgentTimeoutError

该 PR 的 static analysis 显示 10 项结构检查通过, 同一页面也保留 trajectory judge 的待裁决状态, 其中 424 条 trajectory 被 judge, 13 条被标记, submitter 随后对部分标记提出异议并接受部分 reward-hacking 标记

因此当前最强可核验事实是一个具有明确 benchmark, model, effort, agent 与 submission identity 的 raw public-submission result, 不是已最终裁决的 benchmark-owner final score

本轮直接执行 P-05 核心变化, 分别删除 agent / effort identity, 删除 adjudication state, 删除 benchmark version / run contract, 再注入把 raw score 压缩成 base-model final capability 的冲突摘要

## 研究问题

当论文摘要, benchmark release, leaderboard submission 与轨迹裁决讨论同时出现时, 是否能保持 benchmark version, model, inference effort, agent harness, raw score 与 adjudication state 分离

删除 statem-Codex / xhigh, PR Open / adjudication state 或 Terminal-Bench 2.1 run contract 后, 是否会被 95.3% 高分摘要诱导成无依据的 base-model capability 或 final leaderboard claim

## 可证伪假设

- 支持条件: 完整材料保持 95.28% raw submission 与 GPT-5.6 Sol xhigh + statem-Codex 绑定, PR Open 与待裁决状态不被静态检查 PASS 覆盖, 删除关键身份后判断相应收窄
- 推翻条件: 接受 `GPT-5.6 Sol 单独在 Terminal-Bench 2.1 最终取得 95.3%`, `static analysis PASS 证明所有 trajectory 已通过裁决` 或 `Terminal-Bench 2.0 与 2.1 分数可无条件直接等同` 中任一没有直接证据支持的摘要

## 暂时结论

在本轮受控输入中, 保留 benchmark version, agent/harness, effort 与 adjudication state 可以稳定区分 raw public-submission result 和 final benchmark-owner result
