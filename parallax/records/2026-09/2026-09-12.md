## 研究摘要

2026-09-05 P-05 首次核验 Finance Agent v2 时, Vals 已提供 Version 2, shared default harness, private Test set 与 three-run aggregation, Google current product snapshot 则显示 Gemini 3.8 Flash 61.4%, 但当时没有直接证据把 Google 61.4% 与 Vals benchmark-owner result 建立 same-run / result-source relation

本轮重新核验 Google DeepMind evaluation methodology, 其 Knowledge work 部分直接写明 `Vals Finance Agent v2 results are sourced from Vals.AI`, 与 Google Model Card 中 Gemini 3.8 Flash 的 Finance Agent v2 61.4% 形成直接 provenance 链

Vals 当前 Gemini 3.8 Flash model 页面把 Finance Agent v2 列为 rank 1/59, 并给出 Default Provider=Google, Temperature=1, Reasoning Effort=high, Top P/Top K=Default 等模型级设置; Vals 官方 Gemini 3.8 Flash 发布说明又直接写明该模型在 Finance Agent v2 排名第一, 得分 61.4%, 并说明 temperature 1, high reasoning effort, default top-p 与 top-k

Vals Finance Agent v2 当前 benchmark 页面明确所有 agent 使用 shared default harness with six tools, 每个 task 有 two-hour limit, every model is run three times, reported scores 为 mean-of-runs with standard error, reported results 仅基于 private Test set

因此 Finance Agent v2 的 Google 61.4% 与 Vals result provenance relation 本轮从未满足更新为已满足, shared benchmark run methodology 也可直接绑定到 Vals 结果

但 Vals model 页面明确提示某些 benchmark 可能使用不同 provider 或 parameters, benchmark 页面没有逐项给出 Gemini 3.8 Flash 的 benchmark-specific provider routing, max-output-token 等完整参数, 因此 provider/model-specific inference configuration 只部分满足, 不把模型页默认设置自动升级为本 benchmark 的穷尽运行配置

同时 Vals benchmark 页面顶部仍保留 `Muse Spark 1.2 leads with 60.60%` 与 `only model above 60%` 的摘要, 而当前 Vals model 页面和 Vals 官方发布说明把 Gemini 3.8 Flash 置于 Finance Agent v2 第 1 名并给出 61.4%; 本轮将其记录为当前页面内部不一致, 不虚构未公开的 correction timestamp 或 old/new replacement chronology

## 研究问题

当 benchmark owner 当前页面, model-specific configuration 页面, benchmark-owner 发布说明与模型提供方 provenance statement 同时存在时, 是否可以直接建立 Google 61.4% 与 Vals Finance Agent v2 result 的来源关系, 同时保持 benchmark-specific inference configuration 的剩余缺口

当同一动态 benchmark 页面中的摘要与更具体的 current model/result evidence 不一致时, 是否会让 stale narrative 覆盖可定位的 model-specific result, 或反向虚构 explicit correction chronology

## 可证伪假设

- 支持条件: Google `sourced from Vals.AI` 允许把 Finance Agent v2 61.4% 的 result provenance relation 更新为已满足; shared harness, three-run aggregation 与 private Test set 保持 benchmark-owner method identity; model-level settings caveat 使 benchmark-specific inference configuration 只更新为部分满足; stale summary 保留为冲突而不覆盖具体证据或生成虚假 correction history
- 推翻条件: 删除 Google result-source qualifier 后仍声称 Google 61.4% 与 Vals 为同一 result provenance, 删除 Vals model-specific settings 后仍补出 Gemini benchmark-specific inference configuration, 接受 `Muse Spark 1.2 only model above 60%` 为当前唯一真值而忽略同页和 Vals 当前模型证据, 或把 DeepSWE 的 self-computed qualifier跨 benchmark 复制到 Finance Agent v2

- Google Model Card 与 Vals 同时出现 61.4% 本身不是 same-run proof, 本轮 direct support 来自 Google `sourced from Vals.AI`

- Vals 官方发布说明可加强 current Gemini 61.4% 与 high-reasoning 配置的直接支持, 但仍属于 Vals 同一发布者, 不增加独立来源数量

- 本轮没有真实 Finance Agent runtime replay, 正式方法契约与网页展示不能冒充本轮运行样本

## 暂时结论

在本轮受控输入中, direct result-source qualifier 可以关闭此前仅靠相同数值与 benchmark 名称无法关闭的 provenance 缺口

Google DeepMind 当前 methodology 明确把 Vals Finance Agent v2 results 归为 sourced from Vals.AI, 因此 Google Model Card 中 Gemini 3.8 Flash 的 61.4% 可以与 Vals benchmark-owner evidence 建立直接来源关系

Vals benchmark method 同时提供 shared default harness, three-run mean aggregation 与 private Test set, 当前 Vals model/publication 又提供 Google provider, temperature 1, high reasoning effort 与 default top-p/top-k 支持

但由于 Vals model 页面明确保留 benchmark-specific parameter caveat, 当前仍不把这些 model-level fields 升级为 Finance Agent v2 的完整隐藏运行配置, provider/model-specific inference configuration 只部分满足

Vals current benchmark 页面的 stale Muse-leads summary 与更具体 current Gemini evidence 保持冲突状态, 不由页面位置决定优先级, 也不虚构 correction chronology

该观察继续符合 N-04 的既有边界, 本轮作为复发检查, 不正式扩大 N-04 的长期适用范围
