## 研究摘要

本批次使用两个独立发布体系检查 correction 的时间完整性

Anthropic 2026-07-30 发布一份 evaluation 复盘页面, 当前页面明确写有 `Updated Aug 3`, 并说明纠正了其中一个外部 evaluation 的名称

当前同页 footnote 将该 evaluation 标为 ExploitGym

因此 Anthropic 对象具有原始发布日期, 明确 correction 日期与当前 corrected identity, 可以直接执行 P-04 时间替换核心变化

Google DeepMind 2017-10-04 WaveNet 页面明确说明早期版本把 US English 3rd Party Voice 的 MOS 错写为 4.326, 当前图表显示 WaveNet MOS 为 3.966

该页面没有公开 correction 日期

所以 Google quantitative correction 只能证明旧值与当前修正值关系, 不能补出具体 correction 生效日期

两个对象共同形成一个受控反例: explicit correction 不自动等于 complete correction chronology

## 研究问题

当一个官方 correction 同时具有原始发布日期, 明确 correction 日期与 corrected identity, 而另一个 quantitative correction 只有 old/new value 但没有 correction 日期时, 是否能够分别更新当前判断, 保留历史错误事实, 并拒绝补出缺失的生效时间

## 可证伪假设

- 支持条件: Anthropic dated correction 更新当前 evaluation identity 且不倒写 7 月 30 日原发布历史, Google old/new MOS 保持为可核验 quantitative correction 但 correction date 标为当前无法核验
- 推翻条件: 删除 correction date 后仍补出具体 chronology, 删除 corrected identity 后仍猜测 evaluation 名称, 或把 Google 的 undated correction 写成具有已知具体生效日期

## 实验设计

### Trial A

- 目的: 直接执行 P-04 dated correction 核心变化
- 保持条件: Anthropic page identity, 2026-07-30 publication, 2026-08-03 update, correction relation 与当前 footnote
- 改变条件: 相对原发布状态加入后续明确 correction
- 预期支持结果: current evaluation identity 使用 ExploitGym, 同时保留 7 月 30 日页面曾包含错误名称这一历史事实
- 预期反证结果: correction 不更新 current identity, 或把早期错误历史删除为从未存在

### Trial B

- 目的: 检查 correction date 删除后的边界
- 保持条件: Anthropic correction existence 与 current ExploitGym identity
- 改变条件: 删除 2026-08-03 时间锚点
- 预期支持结果: 可保留存在 correction 与 current identity, 但具体 correction chronology 变为当前无法核验
- 预期反证结果: 在没有时间锚点时仍补写 8 月 3 日生效

### Trial C

- 目的: 检查 corrected identity 删除后的边界
- 保持条件: 2026-07-30 publication 与 2026-08-03 correction note
- 改变条件: 删除当前 ExploitGym footnote identity
- 预期支持结果: 只保留 8 月 3 日发生过 evaluation-name correction, 不猜测 corrected name
- 预期反证结果: 从相邻名称自动补出 ExploitGym

### Trial D

- 目的: 检查独立发布者 quantitative correction 在缺少 correction date 时的边界
- 保持条件: Google DeepMind old value 4.326, current chart 3.966, same US English 3rd Party Voice MOS object
- 改变条件: 加入第二发布者 quantitative correction, 但没有 correction date
- 预期支持结果: current MOS 使用 3.966, old 4.326 保留为错误历史值, correction date 标为当前无法核验
- 预期反证结果: 因 old/new values 明确而自行生成具体 correction 日期

### Trial E

- 目的: 构造主动冲突摘要
- 保持条件: E1 与 E2 全部恢复
- 改变条件: 加入摘要 `Anthropic 在 7 月 30 日已经写成 ExploitGym, Google 在 2017 年 10 月 4 日当天把 MOS 从 4.326 改为 3.966, 两次 correction 都证明底层模型能力在 correction 日发生变化`
- 预期支持结果: 拒绝摘要, 分别保持 publication, correction, current identity 与 measurement-reporting 边界
- 预期反证结果: 把 current corrected state 倒写到原发布时点, 或把 reporting correction 改写为 underlying capability change

## 反例检查

- Anthropic 8 月 3 日 correction note 不能证明 7 月 30 日原文已经使用 corrected name
- 当前页没有保存旧错误 evaluation name 的精确 token, 不能从相邻名称猜测
- ExploitGym current footnote identity 不能证明其他 evaluation 使用同一对象
- Google 2017-10-04 publication date 不能冒充 correction date
- Google old 4.326 与 current 3.966 可以建立 quantitative correction relation, 但不能补出 correction 何时发生
- 3.966 只属于当前图表中的 US English 3rd Party Voice WaveNet MOS, 不推广到其他 voices
- correction 不自动证明 underlying model weights, training state 或 capability 在 correction 时点变化
- 两个发布者的 correction 不能因为都属于 reporting error 而合并成同一历史事件

## 暂时结论

P-04 在新的独立发布者 correction 对象中继续成立

Anthropic explicit 2026-08-03 correction 足以更新当前 evaluation identity, 同时保留 2026-07-30 earlier version 曾含错误名称的历史事实

Google DeepMind quantitative correction 允许把 current MOS 更新为 3.966 并保留 4.326 为错误历史值, 但 correction date 当前无法核验

因此 `存在明确 correction` 与 `具有完整可排序 correction chronology` 必须分开判断

本轮只作为 N-03 复发检查, 不扩大正式长期适用范围
