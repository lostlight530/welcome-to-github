## 研究摘要

OpenAI 在 2026-07-29 发布的 ARC-AGI-3 研究文章直接报告同一 GPT-5.6 Sol 在 public task set 上随 harness configuration 改变出现显著结果差异

文章报告 official harness 下 GPT-5.6 Sol 得分 13.3% RHAE, 在 Responses API harness 中保留 reasoning 并启用 compaction 后得分 38.3%, 同时称 output tokens 约减少 6 倍

本轮不把该差异写成 GPT-5.6 Sol 模型权重自身的 capability improvement, 因为文章明确改变了 execution harness, context retention 与 compaction behavior

今天直接攻击 Parallax 新增的 system configuration identity frontier: 当 base model name 固定但 harness 和记忆/上下文处理方式改变时, benchmark result 是否仍可压缩成单一 model-only capability label

## 研究问题

当 benchmark, public task set 与 base model name 保持不变, 但 reasoning retention 与 context compaction 所在的 harness 改变时, 能否把两个结果视为同一 system configuration 的可直接 model-only comparison

## 可证伪假设

- 支持条件: 完整材料下将 13.3% 与 38.3% 绑定到不同 harness configuration, 删除 harness/settings identity 后停止解释 score delta 的配置来源, 并拒绝把差异改写成模型权重升级
- 推翻条件: primary source 明确证明两次 execution configuration 完全相同, 或在删除 harness/settings identity 后仍有独立证据证明 score delta 来自 model-only change

## 历史背景

2026-09-10 已在 DeepSWE v1.1 研究中建立 `shared harness != independent rerun`, 2026-09-12 又证明 benchmark-specific inference configuration 可能只有部分可核验

当前 METHOD 将 model/system configuration identity, execution identity 与 harness identity 分开, 并把 `同一 base model name 在 reasoning effort, toolset, memory, system prompt surface, harness, sandbox, provider route 或 policy 改变后还能否归因同一 capability object` 列为下一阶段研究 frontier

本轮选择 OpenAI 自己公开的 same-model controlled harness comparison, 因为它直接改变 harness/context behavior, 比仅比较两个 leaderboard entry 更适合攻击 configuration identity

## 实验设计

### Trial A

- 目的: 建立完整 same-model configuration comparison 基线
- 保持条件: GPT-5.6 Sol, ARC-AGI-3 public set, RHAE, 两个 harness 与 E1 完整描述
- 改变条件: 无
- 预期支持结果: 两个 score 分别绑定各自 harness configuration, 不能压缩成无配置标签的单一模型能力值
- 预期反证结果: E1 明确说明两次运行 configuration 相同或差异只来自 model weight change

### Trial B

- 目的: 删除 harness identity
- 保持条件: model, benchmark, public-set role 与 13.3%/38.3% 数值
- 改变条件: 删除 official harness, Responses API harness, retained reasoning 与 compaction 字段
- 预期支持结果: 数值仍可被识别为 E1 报告值, 但 score delta 的配置解释无法从剩余字段恢复
- 预期反证结果: 仅凭同一模型名和两个数值就能合法恢复 harness causality

### Trial C

- 目的: 检查 model-only attribution 错误摘要
- 保持条件: E1 完整事实
- 改变条件: 注入摘要 `GPT-5.6 Sol 自身能力从 13.3% 提升到 38.3%, 证明模型在相同评测配置下提升约三倍`
- 预期支持结果: 拒绝该摘要, 因两次 execution 的 harness/context configuration 明确不同
- 预期反证结果: primary source 支持 same-configuration model-only improvement

### Trial D

- 目的: 删除 dataset role 与 metric identity
- 保持条件: model 与两个 harness 名称
- 改变条件: 删除 `public task set` 与 `RHAE`
- 预期支持结果: 不再把 13.3%/38.3% 扩大为 ARC-AGI-3 所有数据集上的一般 success rate, 也不把百分比解释为普通 accuracy
- 预期反证结果: 数值本身足以恢复 dataset role 与 metric semantics

### Trial E

- 目的: 检查 independent reproduction 边界
- 保持条件: E1 完整公开文章
- 改变条件: 将 `official harness` 误读为 `ARC Prize independently reran and adjudicated the 13.3% and 38.3% comparison`
- 预期支持结果: 拒绝 independent rerun 声明, 因本轮证据只直接建立 OpenAI-reported execution comparison
- 预期反证结果: 当前直接证据明确给出独立 benchmark-owner rerun/adjudication

## 原始观测

- Trial A: E1 直接报告 GPT-5.6 Sol official harness 13.3% RHAE 与 retained reasoning + compaction harness 38.3% RHAE, 并明确强调 benchmark 也测量 API settings, harness design 与 prompting choices

## 暂时结论

本轮支持一个窄结论: 对 agentic benchmark, base model name 不是充分的 evaluated-system identity

在 GPT-5.6 Sol 与 ARC-AGI-3 public task set 固定时, OpenAI 报告 harness/context configuration 改变伴随 13.3% 到 38.3% RHAE 的显著差异, 因此任何 capability attribution 至少需要保留 harness, reasoning-state handling, context management, dataset role 与 metric identity

本轮不独立确认两个 score 的 runtime truth, 不证明 retained reasoning 或 compaction 各自的单变量 causal effect, 不证明 38.3% 可迁移到 held-out set, 也不建立 benchmark-owner independent rerun

当前状态保持观察, 不新增 NOTES finding

## AGI-scale relevance boundary

长期自主 Agent 的 observable capability 是 model weights 与 execution system 的联合产物之一

当 memory retention, context compaction, toolset, harness 或 provider route 改变时, 只保存 model name 会丢失可复现判断所需的 system configuration identity

本轮只建立 epistemic attribution boundary, 不构成 AGI capability claim
