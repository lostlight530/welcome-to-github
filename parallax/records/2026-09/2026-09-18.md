## 研究摘要

OpenAI 在 2026-07-29 发布的 ARC-AGI-3 研究文章直接报告同一 GPT-5.6 Sol 在 public task set 上随 harness configuration 改变出现显著结果差异

文章报告 official harness 下 GPT-5.6 Sol 得分 13.3% RHAE, 在 Responses API harness 中保留 reasoning 并启用 compaction 后得分 38.3%, 同时称 output tokens 约减少 6 倍

本轮继续取得独立 benchmark owner ARC Prize 的 current results surface. ARC Prize 将同一 GPT-6 Astra 分成 Standard harness 与 Provider Adapter harness 两个 ARC-AGI-3 result columns, 并在相同 reasoning effort 下报告成对结果, 例如 Max 为 62.71% versus 98.55%, High 为 54.82% versus 99.95%. ARC Prize 同时把 Provider Adapter 描述为 preserving opaque reasoning state between requests and using compaction for longer conversations

E2 不是 E1 的 exact rerun, 因为 model generation, result object 与 data surface 不同. 它的研究价值是独立 benchmark owner 也把 harness 作为显式 result identity, 并在固定 reasoning-effort row 内保留两个不同 harness 的 score

本轮不把任一差异写成模型权重自身的 capability improvement. 今天攻击的核心仍是 Parallax 的 system configuration identity frontier: 当 base model name 固定但 harness 和记忆/上下文处理方式改变时, benchmark result 是否仍可压缩成单一 model-only capability label

## 研究问题

当 benchmark 与 base model name 保持不变, 但 reasoning-state retention, context compaction 或 harness configuration 改变时, model-only label 是否足以承担 evaluated-system identity; 独立 benchmark owner 是否也会在结果表示中保留 harness identity

## 可证伪假设

- 支持条件: E1 将 13.3% 与 38.3% 绑定到不同 harness configuration; 独立发布者 E2 又在同一 GPT-6 Astra 与同一 reasoning-effort row 下将 Standard 与 Provider Adapter harness 分列并报告不同 score; 删除 harness/settings identity 后停止解释 score delta 的配置来源, 并拒绝把差异改写成模型权重升级
- 推翻条件: 当前直接证据显示 harness configuration 在 score provenance 中可以删除而不改变 evaluated-system identity, 或存在同一 run object 的直接证据证明 score delta 来自 model-only change while execution configuration stays identical

## 历史背景

2026-09-10 已在 DeepSWE v1.1 研究中建立 `shared harness != independent rerun`, 2026-09-12 又证明 benchmark-specific inference configuration 可能只有部分可核验

当前 METHOD 将 model/system configuration identity, execution identity 与 harness identity 分开, 并把 `同一 base model name 在 reasoning effort, toolset, memory, system prompt surface, harness, sandbox, provider route 或 policy 改变后还能否归因同一 capability object` 列为下一阶段研究 frontier

## Identity boundary

本轮必须分开以下 identity

- base model identity: E1 GPT-5.6 Sol; E2 GPT-6 Astra
- benchmark identity: ARC-AGI-3
- dataset/result-surface role: E1 public task set; E2 current ARC Prize verified-results surface, including harness-separated ARC-AGI-3 columns
- metric identity: E1 explicitly RHAE; E2 preserves ARC-AGI-3 score columns without being rewritten into generic accuracy
- harness identity: E1 official harness versus Responses API harness; E2 Standard harness versus Provider Adapter harness
- reasoning-state handling: E1 reasoning discarded versus retained; E2 Standard harness versus Provider Adapter preserving opaque reasoning state
- context management: E1 rolling truncation versus compaction; E2 Provider Adapter uses compaction for longer conversations
- reasoning-effort identity: E2 rows compare harnesses within the same Max/XHigh/High/Medium/Low/None labels rather than mixing effort across the paired table
- execution provenance: E1 OpenAI-reported runs; E2 ARC Prize verified-results surface
- evaluator independence: E2 is independent publisher/evaluator evidence for the structural harness boundary, not an independent reproduction of E1's exact GPT-5.6 run pair

`same base model name` 不等于 `same evaluated system configuration`

`independent publisher corroboration of a boundary` 也不等于 `independent rerun of the exact run object`

## 实验设计

### Trial A

- 目的: 建立 E1 完整 same-model configuration comparison 基线
- 保持条件: GPT-5.6 Sol, ARC-AGI-3 public set, RHAE, 两个 harness 与 E1 完整描述
- 改变条件: 无
- 预期支持结果: 两个 score 分别绑定各自 harness configuration, 不能压缩成无配置标签的单一模型能力值
- 预期反证结果: E1 明确说明两次运行 configuration 相同或差异只来自 model weight change

### Trial B

- 目的: 删除 E1 harness identity
- 保持条件: model, benchmark, public-set role 与 13.3%/38.3% 数值
- 改变条件: 删除 official harness, Responses API harness, retained reasoning 与 compaction 字段
- 预期支持结果: 数值仍可被识别为 E1 报告值, 但 score delta 的配置解释无法从剩余字段恢复
- 预期反证结果: 仅凭同一模型名和两个数值就能合法恢复 harness causality

### Trial C

- 目的: 检查 model-only attribution 错误摘要
- 保持条件: E1 完整事实
- 改变条件: 注入摘要 `GPT-5.6 Sol 自身能力从 13.3% 提升到 38.3%, 证明模型在相同评测配置下提升约三倍`
- 预期支持结果: 拒绝该摘要, 因两次 execution 的 harness/context configuration 明确不同
- 预期反证结果: primary source 支持 same-configuration model-only improvement

### Trial D

- 目的: 删除 dataset role 与 metric identity
- 保持条件: model 与两个 harness 名称
- 改变条件: 删除 `public task set` 与 `RHAE`
- 预期支持结果: 不再把 13.3%/38.3% 扩大为 ARC-AGI-3 所有数据集上的一般 success rate, 也不把百分比解释为普通 accuracy
- 预期反证结果: 数值本身足以恢复 dataset role 与 metric semantics

### Trial E

- 目的: 检查 exact independent reproduction 边界
- 保持条件: E1 完整公开文章与 E2 独立 benchmark-owner results surface
- 改变条件: 将 E2 的存在误读为 `ARC Prize independently reran and adjudicated OpenAI's exact GPT-5.6 Sol 13.3% and 38.3% comparison`
- 预期支持结果: 拒绝 exact-rerun 声明, 因 E2 是不同 model generation/result object 的 independent structural corroboration
- 预期反证结果: 当前直接证据明确给出 ARC Prize 对 E1 exact run pair 的 independent rerun/adjudication

### Trial F

- 目的: 检查 system configuration identity 是否只来自 provider 自述
- 保持条件: E2 的 GPT-6 Astra identity, ARC-AGI-3 result surface 与 reasoning-effort row
- 改变条件: 在每个 fixed-effort row 中对比 Standard harness 与 Provider Adapter harness, 再尝试删除 harness column identity
- 预期支持结果: benchmark owner 本身把 harness 作为独立 column identity, 删除 harness 后无法保持各 score 的 evaluated-system provenance; same-effort paired rows 继续显示 configuration-sensitive result separation
- 预期反证结果: ARC Prize current surface 实际不区分 harness, 或同一 row 的两个 score 可在删除 harness identity 后仍被唯一归属

## 暂时结论

本轮支持一个更强但仍然窄的结论: 对 agentic benchmark, base model name 不是充分的 evaluated-system identity, 而这一边界不只存在于 provider 自述

E1 中 GPT-5.6 Sol 与 ARC-AGI-3 public task set 固定时, OpenAI 报告 harness/context configuration 改变伴随 13.3% 到 38.3% RHAE 的差异. E2 中独立 benchmark owner ARC Prize 对 GPT-6 Astra 将 Standard 与 Provider Adapter harness 明确分列, 并在相同 reasoning-effort row 内报告不同结果

因此 capability attribution 至少需要保留 harness, reasoning-state handling, context management, dataset/result-surface role, metric/result identity 与 execution/evaluator provenance. 但本轮仍不独立确认 E1 exact pair 的 runtime truth, 不证明 retained reasoning 或 compaction 各自的单变量 causal effect, 不把 E1 public-set result推广到 held-out set, 也不把 E2 cross-object corroboration写成 E1 的 independent rerun

当前状态保持观察. 按 METHOD, 本日仍只有一个 research batch; 两个 independent sources 不自动构成两个 batch, 因此不新增 NOTES finding

## AGI-scale relevance boundary

长期自主 Agent 的 observable capability 是 model weights 与 execution system 的联合产物之一

当 memory retention, context compaction, toolset, harness 或 provider route 改变时, 只保存 model name 会丢失可复现判断所需的 system configuration identity

E2 进一步表明 evaluator-facing result schema 自身也可能需要把 harness/configuration 作为一级 identity, 而不是附注 metadata

本轮只建立 epistemic attribution boundary, 不构成 AGI capability claim
