## 研究摘要

Google DeepMind 于 2026-09-02 发布 Gemini 3.8 Flash Model Card

Model Card 将 Gemini 3.8 Flash 描述为 Gemini 3.7 Flash 的下一迭代, 面向 software engineering 与 agentic knowledge workflows, 并列出 Gemini app, Gemini Enterprise Agent Platform, Google AI Studio, Gemini API, Google AI Mode 与 Google Antigravity 等分发渠道

当前产品页同时将 3.8 Flash 标为 General availability, 并公开 Vals Finance Agent v2 61.4%, Harvey's Legal Agent Benchmark 10.0% 与 HLE-Verified 54.9% 等结果

这些事实足以确认新的模型与当前分发状态, 也满足 P-03 在 AI capability / agent lifecycle 方向仅在正式 model card 或明确 live deployment state 出现实质变化时继续的条件

但 Model Card 的 `production-ready agents` 是 intended usage 描述, 不能单独证明跨任务生产可靠性

Model Card 还明确说明当前 automated safety evaluations 使用改进后的 evaluations, 因而不应与此前 Gemini model cards 的 performance results 直接比较

Frontier Safety Assessment 也明确表示 3.8 Flash 相对 3.7 Flash 在该框架领域没有 meaningful new capabilities 或 material increases, 因此不能从 agentic benchmark 或产品用途描述补成新的 T/CCL 结论

## 研究问题

当新的正式 Model Card 同时出现 agentic benchmark, General availability, intended usage 与 Frontier Safety 边界时, 判断是否保持每类证据的对象和语义身份

删除 benchmark identity, live availability identity 或 safety comparability caveat 后, 是否会被剩余的高分数和 `production-ready agents` 描述诱导成无依据的统一生产能力结论

## 可证伪假设

- 支持条件: 完整材料只支持其直接覆盖的 benchmark, 分发状态和官方用途描述, 删除关键身份后判断相应收窄, 不把 intended usage, GA 或单项 benchmark 自动升级为统一生产可靠性或新的 Frontier Safety capability level
- 推翻条件: benchmark 名称删除后仍保留原数值含义, GA 身份删除后仍断言当前生产可用, 或把 `production-ready agents` 与 benchmark 排名组合成官方未给出的生产可靠性或 T/CCL 结论

## 实验设计

### Trial A

- 目的: 建立完整新模型卡与当前产品状态基线
- 保持条件: E1 与 E2 全部直接事实
- 改变条件: 相对历史对象只更换为新发布的 Gemini 3.8 Flash
- 预期支持结果: 分别记录 benchmark, GA, intended usage, limitations 与 Frontier Safety 边界
- 预期反证结果: 把这些字段压成统一生产可靠性结论

### Trial B

- 目的: 直接执行 P-03 关键缺失, 删除 benchmark identity
- 保持条件: 三个数值与 intended usage 保留
- 改变条件: 删除 Vals Finance Agent v2, Harvey's Legal Agent Benchmark 与 HLE-Verified 名称
- 预期支持结果: 数值失去可解释的 benchmark 对象, 拒绝保留原比较结论
- 预期反证结果: 仍把裸数值写成对应 benchmark 或统一 agent capability

### Trial C

- 目的: 检查 availability identity 缺失
- 保持条件: benchmark 与 intended usage 保留
- 改变条件: 删除 General availability 与 distribution channels
- 预期支持结果: 保留能力与用途材料, 但当前 live availability 状态收窄为未知
- 预期反证结果: 从 `production-ready agents` 反推出当前 GA

### Trial D

- 目的: 检查安全结果跨卡比较边界
- 保持条件: 当前 safety percentage changes 与 3.8/3.7 identity 保留
- 改变条件: 删除 `improved evaluations` 与 `not directly comparable with previous Gemini model cards`
- 预期支持结果: 拒绝建立跨历史 model cards 的精确安全趋势
- 预期反证结果: 直接用当前百分点与旧卡数值构造历史改善或退化曲线

### Trial E

- 目的: 主动反例
- 保持条件: E1 + E2 完整
- 改变条件: 注入把 benchmark, GA 与 intended usage 合并为生产可靠性和新 T/CCL 的摘要
- 预期支持结果: 拒绝该摘要, 回到各字段直接范围
- 预期反证结果: 接受摘要并覆盖 Model Card 的 known limitations 与 Frontier Safety assessment

## 暂时结论

本轮支持 P-03 的一般边界: 新 Model Card 与 current GA 出现后允许更新对象生命周期事实, 但每项 capability score, intended usage, availability 与 safety assessment 只能承担自身直接覆盖的命题

删除 benchmark identity 后不能从裸分数补回 benchmark

删除 availability identity 后不能从 `production-ready agents` 补回当前 GA

删除 safety comparability caveat 后不能把当前自动化 safety changes 与旧 model cards 直接做精确历史趋势比较

本轮不建立关于 Gemini 3.8 Flash 真实生产可靠性的新事实, 也不建立新的 Frontier Safety capability level
