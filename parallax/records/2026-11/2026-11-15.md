PR search objects, branch-name search objects, path-specific contents API objects, Git commit search hits and checker execution are separate identity domains. A 404 for one path cannot be generalized to all Parallax files.

## 反例检查

The missing current-date Daily path is a genuine counterexample to any claim that every named Parallax path already existed. It does not rescue the stronger invalid inference that zero PR or branch matches imply absence of existing files. The non-atomic access sequence prevents an exact global snapshot claim. Later same-day readback E8–E9 directly observed PR #992 and its named branch, invalidating any timeless interpretation of the earlier filtered zeros. This is a same-day evidence strengthening, with zero additional Trials, research batches, or independent windows.

## 暂时结论

PARTIAL. Negative collection queries are not negative file-path tests. A named 404 applies only to its specified path at its read cut. The evidence does not establish a complete branch history, an independent publisher corroboration or native checker success.
