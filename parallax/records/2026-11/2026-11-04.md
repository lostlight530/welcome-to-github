## 研究摘要

Two read-only query procedures tested whether an empty open-PR search can be generalized to an empty historical PR set, and whether repository source text can substitute for current delivery metadata. The bounded observations reject both generalizations without claiming exhaustive historical completeness.

## 研究问题

Does zero result from a repository-scoped open-PR search imply there are no historically merged Parallax PRs or that stored PR delivery statements represent current state?

## 可证伪假设

- 支持条件: The open-query returns zero while an explicitly merged-filtered query returns at least one matching PR; historical producer text and later repository artifacts remain separately identifiable
- 推翻条件: Both queries refer to identical status scopes and return the same exhaustive set, or the supposedly historical PR cannot be located with its exact identity

## 历史背景

The 2026-11-03 Daily distinguished a producer-time Draft description from a later merged GitHub PR state. That historical observation is not treated as today's fresh API metadata.

## Identity boundary

An empty predicate-filtered search result is not an empty repository history. Search query, index freshness, PR object, authoring-time body, current PR metadata, commit search and main ref are distinct identity planes.

## 控制条件

Keep repository, publisher and access date fixed. Change only PR status predicate between open and merged for Trial A. Trial B compares current repository text to historical PR search text without asserting a current PR status from body prose.
