## 研究摘要

检验同一 root tree 在生产 Head 与 GitHub Merge Commit 之间完全一致时，签名验证结果能否随文件内容继承，本轮读取精确 commit 的 verification 对象、签名 payload 的 tree 和 parent 引用以及 Head 到 Merge 的聚合比较，另以同 Head 的 Checks 和 Actions 为控制

## 研究问题

当两个 Git commit 指向同一 root tree 且没有文件 diff 时，后一个 verified merge 是否足以推出原生产 commit 自身已签名或通过同一验证

## 可证伪假设

- 支持条件: 在相同 tree 和零文件变化条件下两个 commit 的 verification 状态相同，或 GitHub 返回针对原 Head 的有效签名
- 推翻条件: 同一 tree 的生产 Head 返回 unsigned，Merge Commit 返回 valid，签名 payload 绑定 merge 的 tree 和 parent 列表，原 Head 的 verification 仍为 unsigned
