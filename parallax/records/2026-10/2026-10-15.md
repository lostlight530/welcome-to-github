## 研究摘要

本日研究从 2026-10-14 的 delegated credential identity 转向 discovery metadata 与执行控制的边界: A2A AgentSkill 广告和 MCP `readOnlyHint` 等 tool annotations 是否足以使 orchestrator 推出某个具体工具在当前调用中安全、已授权且不会产生副作用

直接读取 MCP 2026-07-28 Tools 规范、MCP 维护者 2026-03-16 annotation 说明和 A2A v1.0.1 specification, 执行一份本地确定性 synthetic route fixture, 11 个 case-level assertions 与 4 个 aggregate assertions 全部通过

- E1 `Tools`: tool name uniqueness 限于 server, serverInfo name 不保证跨 server 唯一, clients/proxies SHOULD disambiguate collisions

- E2: readOnlyHint 默认 false, destructiveHint 默认 true, idempotentHint 默认 false, openWorldHint 默认 true; maintainer explicitly distinguishes hint from enforcement
- E3: AgentSkill includes required id/name/description/tags and optional securityRequirements, describes agent capability, does not report a tool-call outcome

### Executed synthetic fixture, exact source

```python
from dataclasses import dataclass, replace

@dataclass(frozen=True)
class Route:
    agent: str = 'agent-a'
    skill: str = 'export'
    server: str = 'mcp-a'
    tool: str = 'export'
    read_only_hint: bool | None = True
    publisher_trusted: bool = True
    binding_verified: bool = True
    grant_verified: bool = True
    human_approved: bool = True
    runtime_control_attested: bool = True

def naive(x):
    return x.skill == 'export' and x.tool == 'export' and x.read_only_hint is True

def bounded_policy(x):
    return (x.agent == 'agent-a' and x.skill == 'export' and
            x.server == 'mcp-a' and x.tool == 'export' and
            x.publisher_trusted and x.binding_verified and
            x.grant_verified and x.human_approved and
            x.runtime_control_attested)

base = Route()
cases = {
    'bound_authorized': (base, True, True),
    'same_skill_wrong_agent': (replace(base, agent='agent-b'), True, False),
    'wrong_skill': (replace(base, skill='read'), False, False),
    'same_tool_wrong_server': (replace(base, server='mcp-b'), True, False),
    'wrong_tool': (replace(base, tool='search'), False, False),
    'untrusted_hint_source': (replace(base, publisher_trusted=False), True, False),
    'missing_binding': (replace(base, binding_verified=False), True, False),
    'missing_operation_grant': (replace(base, grant_verified=False), True, False),
    'missing_human_approval': (replace(base, human_approved=False), True, False),
    'missing_runtime_control': (replace(base, runtime_control_attested=False), True, False),
    'no_hint_but_independent_controls': (replace(base, read_only_hint=None), False, True),
}
assertions=0
for label,(state,naive_expected,policy_expected) in cases.items():
    got_naive,got_policy=naive(state),bounded_policy(state)
    assert (got_naive,got_policy)==(naive_expected,policy_expected),label
    assertions+=1
    print(f'{label}: naive={got_naive} bounded={got_policy}')
naive_accepted=sum(naive(s) for s,_,_ in cases.values())
policy_accepted=sum(bounded_policy(s) for s,_,_ in cases.values())
naive_only=sum(naive(s) and not bounded_policy(s) for s,_,_ in cases.values())
policy_only=sum(bounded_policy(s) and not naive(s) for s,_,_ in cases.values())
for got,expected in [(naive_accepted,8),(policy_accepted,2),(naive_only,7),(policy_only,1)]:
    assert got==expected,(got,expected)
    assertions+=1
print(f'cases={len(cases)} assertions={assertions} naive_accepted={naive_accepted} bounded_accepted={policy_accepted} naive_only={naive_only} bounded_only={policy_only}')
```
