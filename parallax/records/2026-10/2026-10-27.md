## 研究问题

Can two successful GitHub Pages deploy runs with the same artifact name and size, together with a current main ref matching the later run, establish identical archived bytes, persistent artifact custody, or verified public-site content

## 可证伪假设

- 支持条件: two distinct successful run IDs have equal artifact name and reported size but unequal digest and head SHA, prior successful run has no currently listed artifact, and current main matches only the later new run
- 推翻条件: either new run has no listed artifact at the current cut, the two reported digests are equal, prior fixed run remains listed, or the current main SHA does not match the claimed later head
- 归因限制: reported ZIP digest difference is not an independently rehashed archive comparison, current listing does not prove downloadable bytes or future custody, and main/head match does not prove publicly served content
