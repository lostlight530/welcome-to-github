## 研究摘要

本日研究跨 Agent 委托中的 identity collapse: A2A Task 进入 `TASK_STATE_AUTH_REQUIRED` 后, 相同 user subject 与 scope 能否证明下游 MCP resource 已获得当前代理的实际授权

## 研究问题

`TASK_STATE_AUTH_REQUIRED` 与相同 `sub`、`scope` 是否足以证明指定下游 resource audience、当前 actor、issuer、凭据有效性及本次 operation grant

## 可证伪假设

- 支持条件: A2A 授权请求与凭据获取分开, MCP 要求 audience validation, RFC 8693 将 current actor 与 prior actors 分开, fixture 能在相同 subject/scope 下产生不同合法判断

## Identity boundary

```text
A2A_AUTH_REQUIRED != CREDENTIAL_ISSUED != OPERATION_AUTHORIZED
SAME_SUBJECT_SCOPE != SAME_AUDIENCE != SAME_CURRENT_ACTOR
```

The `verified`, `operation_granted`, `credential_present` and expiry fields below are synthetic booleans, not cryptographic, OAuth or MCP runtime results; `delegated_gate` expresses only this custom delegated-workflow policy, not a universal MCP conformance rule

```python
from dataclasses import dataclass, replace

@dataclass(frozen=True)
class Evidence:
    subject: str = 'user-1'
    scopes: tuple[str, ...] = ('files:write',)
    audience: str = 'https://mcp-b.example.test/mcp'
    issuer: str = 'https://issuer.example.test'
    current_actor: str | None = 'agent-b'
    prior_actor: str | None = 'agent-a'
    credential_present: bool = True
    unexpired: bool = True
    operation_granted: bool = True
    verified: bool = True

def naive_gate(e: Evidence) -> bool:
    return e.subject == 'user-1' and 'files:write' in e.scopes

def delegated_gate(e: Evidence) -> bool:
    return all((
        naive_gate(e), e.credential_present,
        e.audience == 'https://mcp-b.example.test/mcp',
        e.issuer == 'https://issuer.example.test',
        e.current_actor == 'agent-b', e.unexpired,
        e.operation_granted, e.verified,
    ))

base = Evidence()
cases = {
    'valid_delegated': (base, True),
    'wrong_audience': (replace(base, audience='https://other.example.test/mcp'), False),
    'wrong_issuer': (replace(base, issuer='https://other-issuer.example.test'), False),
    'wrong_current_actor': (replace(base, current_actor='agent-c'), False),
    'prior_actor_not_current': (replace(base, current_actor='agent-a', prior_actor='agent-b'), False),
    'actor_missing': (replace(base, current_actor=None), False),
    'a2a_auth_required_only': (replace(base, credential_present=False), False),
    'expired': (replace(base, unexpired=False), False),
    'operation_not_granted': (replace(base, operation_granted=False), False),
    'unverified_claims': (replace(base, verified=False), False),
    'scope_missing': (replace(base, scopes=()), False),
}
for case, (e, expect) in cases.items():
    assert delegated_gate(e) is expect, case
assert len(cases) == 11
assert sum(naive_gate(e) for e, _ in cases.values()) == 10
assert sum(delegated_gate(e) for e, _ in cases.values()) == 1
assert sum(naive_gate(e) and not expected for e, expected in cases.values()) == 9
print('cases=11 assertions=15 naive_accepts=10 delegated_accepts=1 naive_accepted_negative_cases=9')
```
