## 研究摘要

## 研究问题

Can a successful GitHub Pages deployment run, or the same artifact name and byte count, establish persistent artifact retrievability and identical deployed content at a later access cut

## 可证伪假设

- 支持条件: two successful run objects have same artifact name and size but different recorded digests, and a historical successful upload is absent from its current run artifact listing while a newer successful run has a listed artifact
- 推翻条件: recorded digest or size values actually agree contrary to this comparison, the old run's current artifact list is nonempty at the same access cut, or one of the reported successful uploads did not occur in the captured logs
- 范围限制: this tests a concrete counterexample to universal equivalence, not a causal model of all GitHub retention or a claim that the public Pages site failed
