## 研究摘要

研究 W3C trace context 与 OpenTelemetry span `Ok` 是否足以证明指定 A2A task 已完成、产物已验证且被客户端接受, 直接读取 3 个独立发布者的 4 份官方资料, 本地执行 16 个受控 cases 与 20 项通过断言

结果仅证明在自定义 policy 下 trace-only shortcut 在 9 个 object-evidence negative cases 仍返回 true, 不证明真实服务存在漏洞

## 研究问题

`trace-id` 有效并关联 `Ok` span, 能否代替 task ID、terminal state、artifact ID、digest verification 与 client acceptance 的独立证据

## 可证伪假设

### 最小可重放判定

```python
from dataclasses import dataclass, replace
@dataclass(frozen=True)
class Evidence:
    trace: str = "trace-a"
    span: str = "Ok"
    exported: bool = True
    task: str | None = "task-a"
    state: str = "COMPLETED"
    artifact: str | None = "artifact-a"
    digest: bool = True
    accepted: bool = True
def shortcut(x): return x.trace == "trace-a" and x.span == "Ok"
def bounded(x):
    return all((shortcut(x), x.exported, x.task == "task-a",
                x.state == "COMPLETED", x.artifact == "artifact-a",
                x.digest, x.accepted))
base = Evidence()
assert shortcut(replace(base, task="task-b"))
assert not bounded(replace(base, task="task-b"))
```

此最小例只展示同一判断差异, 上述 20 assertions 的完整执行矩阵以原始观测中的 case 清单和汇总计数限定, 不将简化示例冒充完整 harness 源码
