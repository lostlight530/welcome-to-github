## 研究摘要

2026-07-28 MCP Sampling 被标记 deprecated, 但规范仍保留该功能且规定至少十二个月后才有资格移除, 不等于已经删除

2025-11-25 通过初始化声明 sampling 并使用独立请求; 2026-07-28 改为 request-scoped capability 和 InputRequiredResult / multi-round-trip carrier

Python SDK v2 文档描述 Sample resolver 支持新版 carrier, PHP SDK 文档说明特定 ClientGateway.sample() 在新版路径失败, 不同 SDK API 不能坍缩为协议级结论

本地执行 14 个合成场景和 46 项断言, 全部通过, 结果仅适用于研究者定义的证据闸门

## 实验设计

### Trial A｜规范与 SDK API bounded evidence procedure

- 目的: 区分 deprecated、协议移除、carrier 与 SDK method availability
- 保持条件: MCP Sampling 对象和 2026-10-20 访问切面
- 改变条件: 2025/2026 版本和 Python resolver/PHP gateway
- 预期支持结果: 新版保留规范能力但具体 SDK API 路径不等价
- 预期反证结果: 新版规范明确删除 Sampling 或文档声称所有 API 完全等价
- 实际执行: 阅读 E1-E4, 无 SDK 安装或调用

### Trial B｜合成证据闸门

- 目的: 测试版本、capability、carrier、工具结果缺失与混合内容
- 保持条件: baseline 两个 tool-use ID、两个结果、同一 Python policy

- 预期支持结果: 14-case expected vector 全部通过, 不完整结果被完整 gate 拒绝
