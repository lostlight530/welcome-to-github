## 研究摘要

本批次使用 RFC 9110, httpbin 官方页面, Postman API Network 中的 httpbin 当前文档与 Google Actions Center 状态码契约

五个 Trial 分别保留或移除 HTTP 503, 请求路径, 测试端点契约与响应正文信息, 并加入来源逆序和过载恢复误导摘要

RFC 9110 说明 503 通常对应临时过载或计划维护, 但 httpbin 的 `/status/:codes` 是按请求参数生成状态码的测试端点

因此在本次材料中, 503 状态本身不能证明 httpbin 发生生产故障, 过载或维护

本轮没有取得 `/status/503` 的当前响应字节与响应头, 结论只覆盖已核验的正式语义和端点契约

## 研究问题

当 HTTP 503 来自能够按路径参数生成状态码的测试端点时, 判断能否区分通用状态语义, 请求条件与具体运行原因, 并拒绝把测试响应扩大为真实服务事故

## 可证伪假设

- 支持条件: 仅有 503 时保持具体原因未知, 恢复 `/status/:codes` 契约后识别为受控状态生成, 响应正文缺失与来源逆序不产生过载或恢复时间断言
- 推翻条件: 把 503 直接解释为真实过载, 计划维护或确定恢复时间, 或在删除请求身份后仍把响应归属到 httpbin 测试端点

## 历史背景

N-01 已在 HTTP 404, Crossref HTTP 400 与 OpenAI HTTP 401 材料中记录多义状态不能单独支持具体原因

P-02 的下一复验条件要求在新的日期窗口改用另一项非 GitHub API 与 HTTP 429 或 503, 分别保留与移除请求条件及响应正文

本次选择 httpbin 的状态生成端点, 用受控端点本身作为强反例, 检查通用 503 语义是否会被错误扩大为生产事故

## 控制条件

- 判断对象固定为 HTTP 503 与 httpbin 状态生成端点
- 评价字段固定为状态语义, 请求路径, 端点契约, 响应正文, Retry-After 与具体原因
- Trial A 使用 E1 至 E4 完整材料
- Trial B 只保留 HTTP 503 与 E1, 删除请求路径和端点身份
- Trial C 恢复 E2 与 E3 的对象身份和请求契约, 保持当前响应字节未知
- Trial D 保留响应正文缺失信息, 再删除请求路径和端点契约
- Trial E 恢复全部材料, 逆转来源顺序并加入 C1

## 实验设计

### Trial A

- 目的: 建立完整证据基线
- 保持条件: 503 语义, httpbin 身份, 请求路径与端点契约
- 改变条件: 无
- 预期支持结果: 识别受控状态生成, 不形成真实事故归因
- 预期反证结果: 把 503 解释为已确认过载或维护

### Trial B

- 目的: 检查状态码单独保留
- 保持条件: HTTP 503 与 RFC 通用语义
- 改变条件: 删除对象身份, 请求路径与端点契约
- 预期支持结果: 只保留临时不可用语义类别, 具体原因未知
- 预期反证结果: 选择过载或维护作为确定原因

### Trial C

- 目的: 检查请求条件恢复
- 保持条件: E1 至 E3
- 改变条件: 恢复 httpbin 身份与 `/status/:codes` 契约, 不增加实时响应字节
- 预期支持结果: 判断收窄为测试端点受控生成状态
- 预期反证结果: 仍把状态视为真实生产故障

### Trial D

- 目的: 检查空正文是否能够独立归因
- 保持条件: HTTP 503 与没有响应正文
- 改变条件: 删除请求路径和端点契约
- 预期支持结果: 空正文不增加具体原因或恢复时间
- 预期反证结果: 从空正文推断过载, 维护或五分钟恢复

### Trial E

- 目的: 检查来源顺序与误导摘要
- 保持条件: E1 至 E4 完整材料
- 改变条件: 逆转来源顺序并加入 C1
- 预期支持结果: 拒绝 C1, 保持受控端点和未知实时状态边界
- 预期反证结果: 后出现的摘要覆盖端点契约

## 原始观测

### Trial A 输出

RFC 的通用 503 语义与 httpbin 的受控状态端点契约同时成立

### Trial E 输出

来源逆序没有改变判断边界

C1 的过载原因与五分钟恢复时间均没有直接证据, 输出拒绝该摘要

## 反例检查

- httpbin 状态端点可以按请求参数生成指定状态, 反驳每个 503 都代表真实生产事故
- RFC 9110 同时允许临时过载与计划维护, 反驳 503 必然只有一个具体原因
- RFC 9110 只说明可以发送 Retry-After, 不能补出本次恢复时间
- Google Actions Center 的 503 契约只约束其自身 API, 不能跨对象解释 httpbin
- 没有当前响应字节不等于端点没有响应, 也不支持虚构正文或响应头

反例成立并限制本次观察

## 暂时结论

本批次形成 P-02 第六个研究批次与第六个执行窗口
