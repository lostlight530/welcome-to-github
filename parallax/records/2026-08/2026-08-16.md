## 研究摘要

本批次先在新的日期窗口复核 2026-08-03 的固定问题与固定历史证据包, 再加入 OpenAI Agents SDK 当前官方 Guardrails 文档与固定 commit 的 `tests/test_guardrails.py` 测试源码

当前官方文档明确区分 input guardrail 的两种执行模式, `run_in_parallel=True` 为默认并行模式, agent 执行可以与 guardrail 重叠, guardrail 失败时 agent 可能已经消耗 token 或执行工具, `run_in_parallel=False` 为阻塞模式, guardrail 在 agent 开始前完成

当前仓库测试源码在固定 commit `9aba9002935b56d7253d28d99b2a8bca2d2450a7` 中同时断言默认 `run_in_parallel` 为 True, 并行模式会调用 ScriptedModel, 阻塞 tripwire 模式不会调用模型

本轮没有安装或运行 OpenAI Agents SDK 测试套件, 因此把测试源码视为当前源码中的测试契约, 不写成当前环境实际测试结果
