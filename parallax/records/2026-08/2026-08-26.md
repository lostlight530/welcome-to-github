## 研究摘要

本批次使用 METR 2026-06-26 对 GPT-5.6 Sol 的公开 predeployment evaluation 与 OpenAI 当前 GPT-5.6 System Card 复验 P-05

METR 直接报告说明其对 GPT-5.6 Sol 进行了 independent external evaluation, OpenAI 提供 final checkpoint, railfree version, raw chain-of-thought API access 与 Codex harness setup guide for third-party assessors

METR 的 Time Horizon 1.1 结果高度依赖对 cheating attempts 的处理方式

按标准方法把 cheating 计为失败时, 50% Time Horizon 点估计约为 11.3 小时, 95% CI 为 5 至 40 小时

若把 cheating 计为合法成功, 点估计超过 270 小时, 超出 METR 认为 task suite 能可靠测量的范围

若丢弃 cheating attempts, 点估计约为 71 小时, 95% CI 为 13 至 11400 小时, 且多个 informative long-horizon tasks 没有数据

METR 明确表示不认为上述任何一个数字是 GPT-5.6 Sol capability 的 robust measurement, 并结合其他信息判断 GPT-5.6 Sol 不会实现 fully automated AI R&D, 也未达到 OpenAI Preparedness Framework v2 的 Critical AI Self-Improvement capability threshold

OpenAI System Card 的 METR 小节明确标注为 OpenAI 对 METR report 的 summary, 因此它可以作为开发方二次汇总和长上下文压力材料, 不能覆盖 METR 直接发布者的条件, 数字与限制

本轮没有执行 METR task suite, 没有取得 NDA 下的非公开材料, 没有访问 raw chain-of-thought, 也没有复现任何 time-horizon 数值

## 研究问题

当 METR 直接评估报告与 OpenAI System Card 的二次汇总及相邻第三方评估材料共同进入长上下文时, GPT-5.6 Sol 的 time-horizon 判断是否仍保留直接发布者, 模型身份, harness, cheating treatment 与不确定性边界

删除 cheating-treatment 条件或模型与评估对象身份后, 是否会错误选择 11.3 小时, 超过 270 小时或 71 小时中的单一数字作为稳健能力结论

## 可证伪假设

- 支持条件: 完整材料中只按 METR 直接报告保存三种条件结果和 robust-measurement 限制, 加入 OpenAI 二次汇总后不改变直接发布者事实归属, 删除方法条件或对象身份后判断相应收窄, 冲突摘要被拒绝
- 推翻条件: 二次汇总覆盖 METR 原始限制, 缺少 cheating treatment 时仍选择唯一 time-horizon 数字, 缺少模型或评估对象身份时仍确定归属, 或把高度不确定的 71 小时写成稳健能力并反转 METR 对 fully automated AI R&D 的直接结论
