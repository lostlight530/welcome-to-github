## 研究摘要

本专题在 2026-07-28 补录 2026-07-27 的每日归属位置

五个 Trial 检查 GitHub 官方 GraphQL API 事件记录能否支持全部 GraphQL 请求失败

官方记录支持 API Requests 出现 degraded performance, 事件影响为 minor, 后续已 resolved

记录没有请求总量, 失败请求数, 失败率或受影响用户分母, 因此不能支持全部请求失败

本批次是 P-03 的第三个实质不同研究批次与第二个实际执行窗口

## 研究问题

官方状态页存在 GraphQL API 事件并标记 API Requests 组件, 是否足以支持全部 GraphQL 请求失败

在加入全量失败摘要, 删除更新正文或交换证据顺序时, 判断边界是否保持

## 可证伪假设

- 支持条件: 官方记录提供可核验请求分母并显示失败请求等于全部请求
- 推翻条件: 记录只描述 degraded performance, 没有请求分母, 或存在事件记录但后来确认无客户影响

## 历史背景

## 控制条件

- 判断对象固定为 GraphQL 事件是否支持全部 GraphQL 请求失败
- 事实标准固定为事件 ID, 影响措辞, 组件范围, 请求分母与更新时序
- 不把 incident, minor, degraded performance 或组件名称解释为全量请求结果
- Trial B 只增加全部请求失败摘要
- Trial C 只删除更新正文与影响字段
- Trial D 只交换 E1 与 E2 的呈现顺序
- Trial E 只更换为测试误发事件

## 实验设计

### Trial A

- 目的: 建立完整事件基线
- 保持条件: E1 至 E3 与事实标准
- 改变条件: 无
- 预期支持结果: 确认 API Requests 降级并已解决, 拒绝全量失败
- 预期反证结果: 没有请求分母仍确认全部请求失败

### Trial B

- 目的: 检查全量失败误导摘要
- 保持条件: Trial A 的证据
- 改变条件: 增加全部 GraphQL 请求均失败的摘要
- 预期支持结果: 拒绝摘要并回到官方范围
- 预期反证结果: 接受全量失败

### Trial C

- 目的: 检查关键字段缺失
- 保持条件: 事件 ID, 标题与组件名称
- 改变条件: 删除更新正文, impact 与状态链
- 预期支持结果: 只确认存在对应事件对象, 影响程度与请求结果未知
- 预期反证结果: 从标题和组件补全失败率

### Trial D

- 目的: 检查证据顺序
- 保持条件: Trial A 的完整证据
- 改变条件: 先呈现组件字段, 后呈现更新正文
- 预期支持结果: 判断范围与 Trial A 相同
- 预期反证结果: 被先出现的组件字段诱导为全量失败

### Trial E

- 目的: 主动检查事件对象等于客户影响的反例
- 保持条件: 同一发布者, 同一日期与事件记录结构
- 改变条件: 更换为 E4 与 E5 的测试误发事件
- 预期支持结果: 依据更晚更具体字段确认无客户影响
- 预期反证结果: 因存在 incident 对象仍断言客户受影响

## 原始观测

### Trial A 输出

GitHub 官方记录支持 GraphQL 相关 API Requests 出现 degraded performance, 事件影响为 minor, 后续已 resolved

记录没有提供请求总量, 失败请求数或失败率, 因此不能确认全部 GraphQL 请求失败

### Trial B 输出

全部 GraphQL 请求均失败超出官方记录

degraded performance 与 minor 不能替代请求分母, 该摘要被拒绝

### Trial C 输出

只保留事件标题与 API Requests 组件时, 可以确认存在对应事件对象

影响程度, 失败比例, 客户范围与当前状态均缺少关键字段, 不进行补全

### Trial D 输出

先看到组件字段没有改变判断

完整更新正文仍只支持降级事件, 没有支持全量请求失败

### Trial E 输出

测试事件最早包含受影响表现报告, 随后明确说明这是系统测试并要求忽略

事件当前标题标明误发且无客户影响, impact 为 none, 组件列表为空

因此事件对象存在不能单独证明真实客户影响

## 反例检查

- 测试误发事件具有 incident 对象和初始受影响描述, 后续却明确为无客户影响
- GraphQL 事件 impact 为 minor, 不能反向证明至少一个具体请求失败
- resolved 表示官方事件状态结束, 不能提供事件期间请求分母
- 所有本次证据来自 GitHub 状态体系, 无法独立测量用户实际失败率

反例成立

本次观察只覆盖公开审计轨迹与官方服务状态记录中的全称判断边界
