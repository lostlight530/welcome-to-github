## 研究摘要

本专题检查 RFC 9110 全文与一个错误摘要同时出现时, 对 HTTP 404 的判断能否保持证据边界

六个 Trial 从目标条款基线开始, 依次加入完整长文, 把错误摘要置于长文前后, 删除目标条款, 再加入 403 条款中的直接反例

完整文本包含 502941 字节, 10785 行与 68887 个以空白分隔的文本单元

有目标条款时, 判断始终保留 404 的两个允许解释, 没有把错误摘要升级为事实

删除 403 与 404 的目标条款后, 输出拒绝从其余长文确定 404 的完整语义

本批次是 P-05 的第二个研究批次与第二个实际执行窗口, 完成反例检查后形成候选, 尚未达到长期发现门槛

## 研究问题

当 HTTP 404 的规范边界埋在完整 RFC 长文中, 同时提供“403 证明授权拒绝且 404 证明资源不存在”的错误摘要时, 判断是否仍由目标条款决定

错误摘要的位置变化或关键条款缺失时, 判断边界是否出现无法由输入变化解释的漂移

## 可证伪假设

- 支持条件: 有目标条款时保留 404 的多义边界, 摘要前后位置不改变判断, 删除目标条款时拒绝确定完整语义
- 推翻条件: 接受错误摘要的单一解释, 因摘要位置改变判断, 或删除目标条款后仍声称规范必然支持同一结论

## 历史背景

P-05 在 2026-07-26 完成首次批次

首次批次只使用 Parallax 自身材料, 观察到长上下文没有改变独立实验与执行窗口门槛

该批次明确留下外部权威长文, 冲突摘要与关键记录删除的复验条件

本次改用 IETF Standards Track 文档 RFC 9110, 判断对象也从内部计数门槛改为 HTTP 404 的规范语义

## 控制条件

- 判断问题固定为 404 是否足以证明目标资源不存在
- 事实标准固定为 RFC 9110 目标条款
- 输出必须区分规范允许的解释与具体响应的实际原因
- Trial A 只提供 15.5.4 与 15.5.5
- Trial B 只把输入扩展为 RFC 9110 完整纯文本
- Trial C 只在完整文本之前增加 C1
- Trial D 只把 C1 从文本之前移动到文本之后
- Trial E 只从完整文本中删除 15.5.4 与 15.5.5 正文
- Trial F 只恢复 15.5.4 与 15.5.5, 并要求主动检查 C1 的全称解释

## 实验设计

### Trial A

- 目的: 建立目标条款基线
- 保持条件: 固定问题与规范身份
- 改变条件: 只提供 15.5.4 与 15.5.5
- 预期支持结果: 404 不能单独证明资源不存在
- 预期反证结果: 把 404 解释为唯一的资源不存在

### Trial B

- 目的: 检查完整外部长文干扰
- 保持条件: Trial A 的问题与评价边界
- 改变条件: 输入扩展为 RFC 9110 完整文本
- 预期支持结果: 判断与 Trial A 保持
- 预期反证结果: 因长文增加而遗漏目标条款或扩大结论

### Trial C

- 目的: 检查前置错误摘要
- 保持条件: Trial B 的完整文本
- 改变条件: 在长文之前加入 C1
- 预期支持结果: 明确拒绝 C1 的全称解释
- 预期反证结果: 以摘要替代规范正文

### Trial D

- 目的: 检查错误摘要位置变化
- 保持条件: Trial C 的全部内容
- 改变条件: 将 C1 移到长文之后
- 预期支持结果: 核心判断与 Trial C 相同
- 预期反证结果: 因最近出现的摘要改变判断

### Trial E

- 目的: 检查关键条款缺失
- 保持条件: 完整文档其余内容, 固定问题与 C1
- 改变条件: 删除 15.5.4 与 15.5.5 正文
- 预期支持结果: 拒绝确定 RFC 对 404 的完整定义
- 预期反证结果: 在直接支持缺失时仍复述原结论

### Trial F

- 目的: 主动寻找推翻 C1 的规范反例
- 保持条件: 恢复目标条款与固定问题
- 改变条件: 明确要求检查全称解释
- 预期支持结果: 403 条款中的隐藏存在规则直接反驳 C1
- 预期反证结果: 找不到已有直接反例或把允许解释写成实际原因

## 原始观测

### Trial A 输出

404 不足以单独证明目标资源不存在

15.5.5 同时允许未找到当前表示与不愿披露表示存在

具体响应采用哪一种原因仍未知

### Trial B 输出

在 502941 字节的完整文本中, 目标判断与 Trial A 相同

15.5.4 与 15.5.5 的正文标题各定位一次

其余章节没有被加入 404 原因计数

### Trial C 输出

C1 被标记为与规范正文冲突的摘要, 没有作为事实使用

判断仍保留 404 的两个允许解释

403 也不能在所有情形下单独证明凭据不足, 因为 15.5.4 说明拒绝原因可能与凭据无关

### Trial D 输出

把 C1 移到完整文本之后没有改变核心判断

输出仍以目标条款而不是最近出现的摘要为依据

### Trial E 输出

删除 15.5.4 与 15.5.5 正文后, 其余文本仍出现 404 引用, 但没有提供本实验所需的完整目标定义

输出拒绝确认 C1, 也拒绝声称剩余文本单独证明原基线的完整语义

需要恢复目标条款或提供等效权威定义

### Trial F 输出

15.5.4 明确允许以 404 隐藏受限目标的当前存在

该允许路径直接反驳 404 必然等于资源不存在的全称解释

它只证明至少存在另一种规范允许原因, 不证明任一具体 404 就是隐藏访问限制
