## 2026-09-18 research-system synthesis

### 1 Evidence identity and support

研究反复证明一个判断必须携带足够 evidence identity 才能稳定.

目前反复出现的关键字段包括 publisher, primary/derived source, object, benchmark, dataset, metric label, correction relation 与 dynamic-page access time.

页面数量不能替代 publisher independence. 同一 benchmark 名称不能替代 same-run identity. 动态页面 current text 不能替代 historical snapshot.

2026-09-18 同一 Daily 内新增第二独立发布者 ARC Prize, 但 source independence 没有被误计为第二 research batch.

### 2 Temporal and current-state correctness

9 月 2, 4, 6, 7, 8, 14, 16, 17 日持续攻击旧状态与新状态的关系.

当前稳定边界是 newer valid evidence 可以更新 current judgment, 但不能删除 earlier true state. 同时 current docs, current incident terminal state 与 individual object completion 继续保持不同证据职责.

### 3 Execution, harness and evaluator provenance

9 月 5, 9, 10, 11, 12, 13, 18 日把 benchmark result 拆成 benchmark version, dataset split, model, reasoning state, harness, execution identity, publisher, evaluator 与 adjudication state.

2026-09-18 新增并强化 same-model configuration switch 观察: OpenAI 对 GPT-5.6 Sol 的 ARC-AGI-3 public-set comparison 明确改变 harness/context handling; ARC Prize current GPT-6 Astra result surface 又在 fixed reasoning-effort rows 内把 Standard 与 Provider Adapter harness 分成不同结果 columns, 例如 Max 62.71% vs 98.55%, High 54.82% vs 99.95%.

ARC Prize 将 Provider Adapter 描述为 preserving opaque reasoning state between requests and using compaction for longer conversations. 该独立 benchmark-owner evidence 支持 `harness/configuration belongs to evaluated-system identity`, 但不是 OpenAI GPT-5.6 Sol 13.3%/38.3% pair 的 exact independent rerun.

当前重要限制是 `shared harness != independent rerun`, `leaderboard display != independent execution`, `same base model != same system configuration`, `independent structural corroboration != exact run reproduction`.

### 4 Capability, deployment and semantic outcome

9 月 3, 13, 15, 18 日把 capability, intended use, deployment availability, development-set evidence, execution configuration, execution progress 与 semantic success 分离.

一个数值没有 metric identity 时不能靠邻近字段恢复 meaning. 一个 run receipt 的 `completed` 不能自动翻译为 successful task count. 一个 benchmark score 也不能在删除 harness/configuration 后继续被解释为 model-only capability.

## AGI-scale epistemic integrity

Parallax 下一阶段不研究 `某模型是不是 AGI`.

研究对象升级为 `长期自主 Agent 如何在不断变化的世界中保持可追溯且不越界的判断`.

这要求把当前已有的 evidence discipline 扩展到.

- multi-agent delegated evidence chain
- tool and retrieval provenance
- world-state drift during long deliberation
- model/system configuration identity across toolset, memory, reasoning effort and harness changes
- evaluator independence and result ownership
- aggregate recovery versus per-object completion
- correction chronology across continuously updated public systems

这些方向当前是 frontier, 不是新的 CASE 支持或 NOTES finding.

## 下一阶段 Daily 优先队列

### Delegated evidence chain

构造由多个 Agent 或工具分别提供 source, extract, summary 与 conclusion 的链条. 主动删除 primary source identity, 替换同 publisher mirror, 注入 stale subclaim 与 conflicting authority, 检查最终判断是否仍能定位真实 support.

### World-state drift during deliberation

固定 initial evidence cut S0, 在 decision 前引入 S1. 比较不重读, selective reread 与 current-state rebinding, 检查 historical truth 和 decision-time truth 是否被混合.

### System configuration identity

2026-09-18 已取得 OpenAI same-model different-harness primary-publisher observation, 并在同一 Daily 内取得 ARC Prize benchmark-owner cross-object structural corroboration 与 same-effort paired harness rows. 下一步不重复这两个页面制造新批次, 优先取得 exact GPT-5.6 independent evaluator rerun, raw run bundle, harness commit/config hash 或单变量 configuration comparison.

### Per-object completion

选择具有 aggregate recovery 的真实 production object, 尝试取得 individual session, queued item, job 或 task 的 terminal evidence. 无法取得时保持 aggregate-only boundary.

### Cross-evaluator comparability

优先寻找同一 benchmark 下 provider, benchmark owner 与独立 evaluator 的 run-level provenance, 直接测试 same-run, independent rerun 与 adjudication relation. 2026-09-18 已证明 independent publisher 可以 corroborate structural identity boundary 而仍不足以建立 exact same-run relation.
