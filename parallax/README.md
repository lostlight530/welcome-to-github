# Parallax

Parallax 记录同一对象在证据、时间与上下文变化时出现的观察差异

这里不追求固定措辞, 也不把单次输出升级为结论

## 阅读顺序

1. METHOD.md 说明证据闸门与结论升级规则
2. CASES.md 保存控制案例与复验状态
3. records/YYYY-MM.md 保存月度索引
4. records/YYYY-MM/YYYY-MM-DD.md 保存可独立阅读的每日记录
5. NOTES.md 只接收通过长期门槛的发现

## 收录边界

- 事实必须能够追溯到公开权威来源或可复现实验
- 推断与未验证事项必须显式标记
- 宣传词, 二手转述和来源数量不能单独支撑结论
- 不保存私人信息, 内部提示词, 隐藏权重或其他目录内容
