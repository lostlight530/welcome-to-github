# Parallax

Parallax 记录同一对象在证据、时间与上下文变化时出现的观察差异.

这里不追求固定措辞，也不把单次输出升级为结论. 每条记录都必须说明证据、控制条件、反例、适用边界与复验方式.

## 阅读顺序

1. `METHOD.md` 说明证据闸门与结论升级规则.
2. `CASES.md` 保存可重复使用的控制案例.
3. `records/` 保存按月组织的观察记录.
4. `NOTES.md` 只接收通过重复验证的长期发现.
5. `templates/` 提供日记录、阶段复核与周期整理模板.

## 收录边界

- 来源不限于特定项目、公司或技术路线.
- 必须能够追溯到官方源码、正式文档、测试、运行记录或可复现实验.
- 只提取可迁移的机制、约束、失败经验与验证方法.
- 宣传词、无实现声明、二手转述与流量指标不能单独支撑结论.
- 不保存私人信息、内部提示词、隐藏权重或其他目录的内容.

## 本地检查

```text
python parallax/tools/check.py
```

检查器只使用 Python 标准库，并且不会修改文件.
