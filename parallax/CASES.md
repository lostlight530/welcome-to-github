# 控制案例

## P-01 重复观察

- 输入: 同一组固定证据与同一问题
- 变化: 在不同时间重新执行
- 检查: 事实, 证据等级, 判断边界与置信度是否无理由变化
- 最近实际执行日期: 2026-07-20
- 累计研究批次: 1
- 独立执行窗口: 1
- 当前状态: 观察
- 已知反例: 官方文档可能落后于实现, 产品声明缺少独立运行证据
- 下一复验条件: 使用不同项目和来源顺序复验
- 关联记录: records/2026-07.md

## P-02 冲突来源

- 输入: 两个结论冲突且证据强度不同的来源
- 变化: 调换来源顺序
- 检查: 结论是否由证据强度决定, 而不是由出现顺序决定
- 最近实际执行日期: 2026-07-24
- 累计研究批次: 3
- 独立执行窗口: 3
- 已覆盖实验类型: 顺序交换, 关键条件缺失, 误导摘要, 实时证据更新, 404 反例, 跨发布者冲突, 隐藏评价字段
- 当前状态: 发现
- 已知反例: 同一发布者与显式评价字段限制已复验, 当前适用范围仍限于保护机制与 HTTP 404
- 下一复验条件: 改用非 GitHub API 与不同错误状态, 保持开放式问题和直接反例
- 关联记录: [2026-07-21](records/2026-07/2026-07-21.md), [2026-07-23](records/2026-07/2026-07-23.md), [2026-07-24](records/2026-07/2026-07-24.md)

## P-03 关键缺失

- 输入: 移除形成结论所需的关键条件
- 变化: 保留足以诱导猜测的背景信息
- 检查: 是否明确记录未知并拒绝补全
- 最近实际执行日期: 2026-07-28
- 累计研究批次: 3
- 独立执行窗口: 2
- 已覆盖实验类型: 历史证据缺失, 范围核验, 请求分母缺失, 顺序交换, 误导摘要, 测试误发反例, 主动反例
- 当前状态: 发现
- 已知反例: 远端记录缺失不能证明没有离线工作, 受影响组件与事件对象不能证明全部请求失败, 测试误发事件不能证明客户影响, 动态事件列表的部分核验不能证明全日只有已选事件
- 下一复验条件: 使用公开请求分母或成功率执行有分母更新与失效检查
- 关联记录: [2026-07-22 每日专题](records/2026-07/2026-07-22.md), [2026-07-25 特殊专题](specials/2026-07/2026-07-25-openai-service-events.md), [2026-07-27 每日专题](records/2026-07/2026-07-27.md)

## P-04 时间替换

- 输入: 旧契约与更新后的官方契约
- 变化: 明确两者生效时间
- 检查: 是否更新当前判断, 同时保留历史原因
- 最近实际执行日期: 2026-07-28
- 累计研究批次: 2
- 独立执行窗口: 2
- 已覆盖实验类型: 状态更新, 明确纠正, 顺序交换, 关键状态缺失, 事件身份缺失, 跨事件反例, 历史纠错
- 当前状态: 候选
- 已知反例: 同日事件可以具有不同当前状态, 通用 resolved 模板不能证明真实事故, 动态页面快照不能代表后续状态
- 下一复验条件: 使用另一发布者的 superseded, reopened 或回滚更新链, 分别移除时间戳与稳定事件 ID
- 关联记录: [2026-07-26 每日专题](records/2026-07/2026-07-26.md), [2026-07-28 每日专题](records/2026-07/2026-07-28.md)

## P-05 上下文干扰

- 输入: 固定问题, 核心约束与大量相关或无关材料
- 变化: 增加噪声, 误导摘要或删除关键支持记录
- 检查: 核心约束, 证据计数与结论门槛是否保持
- 最近实际执行日期: 2026-07-26
- 累计研究批次: 1
- 独立执行窗口: 1
- 已覆盖实验类型: 长上下文干扰, 单变量删除, 误导摘要, 主动反例
- 当前状态: 观察
- 已知反例: 当前输入只来自 Parallax, 不能代表外部长文或不同模型
- 下一复验条件: 在新的日期窗口加入外部权威长文, 冲突摘要与关键记录删除
- 关联记录: [2026-07-25 每日专题](records/2026-07/2026-07-25.md)
