## 2. 仓库自身如何体现？ / Repository-native Architecture and Evidence

**中文** — `docs/brain/harvester.py` 在受控 profile 下取回来源并携带溯源；`cortex.py` 管理图谱与索引；`scholar.py` 处理结构扫描；`reason.py` 利用结构信号生成推演观察；`evolution.py` 组织演化循环；`nexus.py` 提供统一入口。`observation_contract.py` 是可规范序列化的观察声明，包含 identity、source、claim、evidence、boundary、supersedes。`docs/brain/README.md` 指出活动 JSONL 是可审计账本、SQLite 是可重建索引、archive 保留历史。`docs/archaeology/ARCHAEOLOGY_INDEX.md` 保存数字考古时间顺序。五仓学科总览已有原始贡献 `DISCIPLINARY_LINEAGE.md`，不因本纪念而覆盖。

**English** — `docs/brain/harvester.py` collects allowlisted source material with provenance; `cortex.py` maintains the graph and query index; `scholar.py` contributes code-structure scanning; `reason.py` interprets structural signals; `evolution.py` coordinates bounded evolution cycles; and `nexus.py` offers a local entrypoint. `observation_contract.py` models identity, source, claim, evidence, boundary, and supersession as canonical declarations. The native `docs/brain/README.md` separates auditable active JSONL ledgers, rebuildable SQLite indexes, and preserved archives. `docs/archaeology/ARCHAEOLOGY_INDEX.md` retains historical navigation. Qí's original `DISCIPLINARY_LINEAGE.md` remains a distinct contribution.

## 3. 人话解释 / In Plain Language

**中文** — 可以把 Welcome 看作**一家有档案馆、资料室、搜索台和公共展厅的研究图书馆**。Harvester 负责收集，Cortex 负责索引，Reason 负责做有界结构分析，Nexus 负责安排流程，Archaeology 保存来路。新报告不能偷偷改掉昨天的事实，搜索结果也不自动等于事实正确。

**English** — Think of a **research library with archives, a catalog, a search desk, and a public exhibition hall**. Harvester collects, Cortex indexes, Reason produces bounded structural analysis, Nexus coordinates, and Archaeology preserves history. A new report does not silently rewrite yesterday's record, and a retrieved item is not automatically true.

## 6. 纪念与升华 / Commemoration and Wider Meaning

**中文** — **会记住，不等于有判断；能检索，不等于有理解。一个成熟 Agent 系统的公共记忆必须既能保存成长，也能保存错误和修正。**

**English** — **Remembering is not judgment, and retrieval is not understanding.** A mature public memory must preserve its growth as well as its mistakes and explicit corrections.
