# PHASE VIII: HUMAN-READABLE DETERMINISM

## 纪元定义

第八阶段标志 NEXUS CORTEX 从机器可运行走向人类可读、机器可验和历史可回放.

系统不再把抓取成功、文件堆积和 Action 绿色状态当作认知闭环.

## 根源问题

旧链路保存完整原文和 Diff，但把机器证据直接暴露为阅读界面.

Current 同时积累多个 SHA 快照，状态文件携带 Runner 绝对路径，来源失败还能被日志吞掉.

JSONL 已具备追加式记忆，却缺少统一递归校验和确定性卫生入口.

## 架构修正

- Current 每个来源路径只保留一个有效版本.
- 旧 SHA 快照进入按年月组织的 archive.
- 状态只保存仓库相对路径，并通过原子替换落盘.
- 外部原文和 Diff 进入折叠证据区.
- 人类阅读层提供结论、指标、导航、风险和建议动作.
- JSONL 递归验证，SQLite 保持可重建索引定位.
- 自动生成中文拒绝中文句号，统一使用英文句号.

## 双自动化边界

Jules 继续自主生成 Horizon SOP 文件和代码 PR.

人类继续承担 Review 与合并闸门.

GitHub Actions 只处理仓内确定性摄取、验证、记忆和报告，不改写 Jules 自主维护目录.

## 验证原则

成功必须由测试、账本统计、Current 唯一性、连续运行零变化和 Git diff 共同证明.

任何关键来源失败、Tree 截断、JSONL 非法或格式违规都必须阻断提交.

## 最终总结

这一阶段拒绝把更多文本当作更多知识.

机器内部保留完整证据，人类界面只呈现可扫描、可比较和可行动的信息.

确定性不只约束计算，也约束记录、语言、失败和维护边界.
